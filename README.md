## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias fundamentais da web, sem o uso de frameworks, para garantir máxima performance e carregamento rápido:

* **HTML5** (Semântica e estruturação)
* **CSS3** (Estilização, animações e Flexbox/Grid)
* **Netlify** (Hospedagem e Deploy contínuo)

## ✨ Principais Funcionalidades

* 📱 **Totalmente Responsiva:** Layout adaptável para smartphones, tablets e desktops.
* ⚡ **Alta Performance:** Código limpo e sem dependências externas pesadas, focado em carregamento rápido para não perder leads.
* 🎥 **Mídia Integrada:** Suporte a player de vídeo otimizado para a carta de vendas (VSL).
* 💬 **Botão Flutuante:** Integração direta com WhatsApp para tirar dúvidas de potenciais alunos.

## 🚀 Como rodar o projeto localmente

Como o projeto foi feito com HTML e CSS puro, não é necessária nenhuma instalação complexa.

```bash
# Clone este repositório
git clone [https://github.com/DanielSousa07/LandingPage-Felipe-Macedo.git](https://github.com/DanielSousa07/LandingPage-Felipe-Macedo.git)

# Acesse a pasta do projeto
cd LandingPage-Felipe-Macedo
```

Após clonar, basta dar um duplo clique no arquivo `index.html` para abri-lo diretamente no seu navegador, ou utilizar a extensão **Live Server** do VS Code.
